🏈 NFL Analytics Portfolio

Welcome to my football analytics portfolio. This repository contains machine learning models, interactive visualizations, and opponent scouting reports built using NFL play-by-play data from nflverse. The objective is to build decision-support tools similar to those used by NFL front offices and coaching staffs to improve game planning, self-scouting, and strategic decision making.

Comprehensive defensive scouting report identifying Seattle's coverage tendencies, defensive strengths, weaknesses, and offensive concepts that generate the highest Expected Points Added (EPA).

Project Objectives

Objective Description
Opponent Scouting Identify defensive tendencies, offensive strengths, and exploitable weaknesses for upcoming opponents.
League Comparison Compare every NFL team using advanced efficiency metrics instead of traditional box score statistics.
Machine Learning Apply statistical learning techniques including PCA, predictive modeling, clustering, and exploratory data analysis.
Decision Support Translate complex football data into actionable coaching recommendations.
